# Lightning

Play as a storm: start as a spark of static and grow until you swallow the galaxy.

## Download (Windows)

**[Download Lightning-windows.zip](https://github.com/chaynes81-ux/lightning-download/releases/latest/download/Lightning-windows.zip)**

1. Unzip it.
2. Run **Lightning.exe**.
3. If Windows says *Windows protected your PC*, click **More info → Run anyway** (the game isn't signed).
